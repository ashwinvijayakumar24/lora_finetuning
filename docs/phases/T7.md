# T7 — does fine-tuning make the model forget? (pre-registered)

Written and committed **before** any T7 code or run (PRD §8.7 asked for a threshold
"stated in advance" but never gave a number; this fixes it).

## Question

Catastrophic forgetting means a model loses general ability while it learns a narrow
task. PlayParse trains a LoRA adapter on one very narrow output format, so it is fair
to ask how much general knowledge the adapted model keeps.

## Design (fixed)

- **Benchmark:** a fixed, seeded sample of **1,000 MMLU questions** (all 57 subjects,
  `cais/mmlu` "all" test split, seed 0), stored in `data/mmlu_1k.jsonl`.
- **Scoring:** 0-shot. The question and its four options go in one user message
  (Llama 3.2 chat template, pinned `CHAT_DATE_STRING`, no system prompt), followed by
  `Answer:`. The predicted answer is the letter (A–D) whose token has the highest
  log-probability. Accuracy is the share of questions answered correctly.
- **Arms:** base Llama 3.2 1B Instruct; base + R5 adapter (merged, bf16); base + T3b
  adapter (merged, bf16).
- **Statistics:** accuracy with a 95% bootstrap CI over questions, and the paired
  difference of each adapter arm vs base.

## Threshold

**T7 is earned if the R5 arm's accuracy is at most 2.0 points below the base model's**
(point estimate decides; the paired CI is reported alongside). The T3b arm is reported
for information only.
